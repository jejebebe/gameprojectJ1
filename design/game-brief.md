# Game Brief: 제이의 모험 (Jei's Adventure)

**One-sentence pitch:** 검은 양갈래 머리 꼬마 여자아이 제이가 적에게서 능력을 빼앗아 길을 여는, 8~12세 아이도 혼자 끝까지 깰 수 있는 세로 화면 도트 플랫폼 액션.

## Core loop
- 달리고 점프해서 장애물과 적을 통과한다
- 적에게서 능력을 획득한다
- 능력을 써서 막힌 구간과 적을 돌파한다
- 레벨 끝에 도달해 다음 레벨로 간다

## Player goal & fail state — what "working" looks like
- 목표: 레벨 3개를 지나 보스를 쓰러뜨린다. 한 레벨은 5분 안팎에 끝낼 수 있어야 한다
- 체력·목숨: 하트로 보이는 체력은 목숨 1개당 3. 시작 목숨 3개
- 실패: 체력이 0이 되면 마지막 체크포인트에서 다시 시작하고 목숨 -1. 아래로 떨어지면 체력과 관계없이 목숨 -1. 다시 시작할 때 체력은 기본값 3
- 게임 오버: 목숨이 0이 되면 진행 상황을 초기화하고 메인 화면으로 간다. 게임 시작을 누르면 처음부터 한다. 반복 도전을 위한 장치
- 체크포인트: 깃발의 X좌표를 지나가면 켜진다 (공중으로 지나가도 켜짐). 새 체크포인트가 켜지면 이전 깃발은 사라진다
- 보너스 체력: 아이템을 먹으면 하트 +1, 보너스는 최대 2개. 죽으면 보너스는 사라진다
- 난이도: 체크포인트를 촘촘하게 둔다. 정밀한 점프 연속 구간 없음. 보스 패턴은 2~3개. 연속 실패 보정은 없다

## MVP — what must exist to be the game
1. 세로 화면 분할 레이아웃: 상단 절반은 게임 화면, 하단 절반은 조작 버튼(이동·점프·능력)과 메뉴 버튼. 이동·점프는 터치 우선, 키보드는 보조
2. 적 3종 (밟기·피격 규칙 포함)
3. 능력 획득 시스템: 적에게서 능력을 얻고 사용, 능력 3종
4. 레벨 3개 (능력에 따라 풀이가 달라지는 구간 포함)
5. 보스 1개
6. 하트 체력(게임 화면 위쪽 표시), 목숨과 게임 오버, 체크포인트 재시작, 보너스 체력 아이템
7. 최소 메뉴와 레벨 선택. 하단 조작 영역에서 열림

## Out of scope — not building this
- 멀티플레이, 월드맵, 레벨 에디터
- 상점·재화·업적
- 스토리 컷신
- 4번째 이상의 레벨, 4번째 이상의 능력
- 세이브 시스템 (이번 MVP에서는 없음)
- 다국어 지원
- 게임패드 지원, 가로 화면 모드
- 광고·인앱 결제·개인정보 수집 (13세 미만 대상 스토어 정책 때문. 출시 전 정책 확인 필요)

## Build order
1. 세로 분할 화면 + 하단 터치 버튼으로 이동·점프 손맛 만들기 (회색 상자 레벨). 재미의 핵심이라 가장 먼저
2. 아이 1~2명에게 직접 해 보게 해서 난이도와 버튼 크기 확인
3. 적 1종과 능력 1종으로 획득 → 사용 루프 증명
4. 레벨 1을 임시 도트 타일로 완성 (완성 아트는 컨셉 샘플 이후 본격 제작 단계)
5. 능력 2종과 적 확장, 레벨 2·3
6. 보스
7. 메뉴와 마감

---
**Who it's for / what they feel:** 8~12세 아이. 혼자서 깼다는 성취감과 능력을 얻는 순간의 짜릿함.

**Art & audio direction:** 도트 픽셀아트, 애니메이션과 이펙트는 스프라이트 시트, 레트로 칩튠 사운드. 주인공 제이: 검은 양갈래 머리의 꼬마 여자아이.

**Reference game:** 슈퍼 마리오 브라더스 3. 스테이지 구조와 점프 조작감만 가져오고, 월드맵과 수십 종의 파워업은 제외.
